01 / Development process

From seed to a hosted MVP

A broad behavior spec. A failed first route. A focused second build.

  1. 01

    Pin down the behavior

    Astra 6 helped turn the seed into 72 questions covering documents, answers, voice, UX, controls and quality.

  2. 02

    The first route failed

    Building directly on GitHub + Vercel expanded beyond the demo. iPad-to-laptop debugging slowed every fix.

  3. 03

    Cut scope to the core

    Keep conversation, question answering and plan selection. Turn the detailed spec into an MVP plan.

  4. 04

    Prove it locally, then host

    Build a working local MVP first. Deploy it through GitHub to Vercel.

The lessonDefine broadly. Scope deliberately. Get it working locally.

02 / Refinement process

Close the gap. Repeat.

Desired behavior meets the working MVP — one guided improvement at a time.

  1. 01

    Keep the goal in view

    The seed requirement stays the touchstone. The product must serve its core purpose.

  2. 02

    Make “better” specific

    Define the look and feel, simpler language, answer behavior and context across follow-up turns.

  3. 03

    Compare desired vs. actual

    Try the working MVP. Identify the concrete gap between what it does and what it should do.

  4. 04

    Guide, close, recheck

    Give the coding agent the desired behavior, guide the fix and assess the result. Repeat across all three goals.

04 / Features at a glance

A conversation, on your terms.

Choose a plan. Set the language and detail. Ask in the way that suits you.

01Plan selection

Pick one of three LIC plans. Questions use that plan’s prepared documents.

02Hindi–English toggle

Switch the interface and new answers between English and Hindi, including speech.

03Language simplicity

Very simple mode uses everyday words and shorter sentences to explain policy terms.

04Complexity control

Choose Very simple, Normal or Technical. The setting applies to new answers.

05Tap to speak

Tap to record; tap again to send. Read the answer, listen to it or keep typing.

06Optional goals

Add what matters to you. New answers use it until you reset or change the product.
